

## Plotting functions

This plotting folder contains scripts focused on visualization utilities for Raman spectroscopy data, particularly for generating and customizing plots. 

 - It includes a script for creating offset graphs, which is useful for stacking and comparing multiple spectra clearly. Offset between multiple traces can be automatically set.
 - It also includes a 2D plotting script for producing standard spectral plots and a customization script for modifying plot appearance, and automated coloring
